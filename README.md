# 2048 Game

一个功能丰富的 2048 游戏实现，支持多种网格大小、难度级别、自定义主题、滑块字体、声音效果、算法/AI 双模式分析、AI 自动操作与跨设备同步。

> **注意**：项目采用模块化结构（`index.html` + `css/` + `features/` + `fonts/` + `manifest/`），请保持目录完整后运行，不要只下载 `index.html`。部分浏览器在 `file://` 协议下可能无法加载外部 JavaScript，建议使用本地 HTTP 服务或[在线体验](https://thefurina.github.io/2048-game/)。

## 项目介绍

这是一个基于 HTML5、CSS3 和原生 JavaScript（ES6+）的 2048 游戏实现。游戏采用模块化架构，界面响应式适配桌面与移动设备，并提供丰富的自定义选项和增强功能。

## 主要功能

- 🎮 **多种游戏模式**: 标准模式和无尽模式
- 📐 **可变网格大小**: 支持3×3到10×10的自定义网格
- 🎯 **难度级别**: 简单、中等、困难三种难度
- 🧠 **AI游戏分析**: 本地算法分析与大模型分析双模式，实时评估最佳移动方向与游戏状态
- 🤖 **AI自动操作**: 根据当前分析模式自动游玩，可暂停、继续、停止，支持屏幕常亮
- 🎨 **主题定制**: 支持浅色、深色、跟随浏览器以及完全自定义主题，支持主题导入/导出
- 📲 **跨设备同步**: 基于 WebRTC 的局域网同步，6 位连接码快速配对并实时同步
- 📳 **振动反馈**: 合并、获胜、失败等关键时刻触觉反馈，可分项开关
- 🔊 **声音效果**: 移动、合并、获胜、失败四类音效，支持音量调节与自定义上传，默认关闭
- 🔤 **滑块字体**: 系统字体、Inter、Nunito、Press Start 2P、JetBrains Mono 五种数字字体，按需加载
- 🖥️ **全屏模式**: 一键全屏沉浸游玩，自动隐藏次要UI
- 🌐 **多语言支持**: 中文、英文与日文界面，可跟随浏览器自动选择
- 🖼️ **分享战绩**: 获胜后可生成战绩图片，支持系统分享或下载
- ✏️ **自定义网页标题**: 使用占位符组合动态标题，包含模式、难度、网格与分数
- 📦 **PWA 与离线**: 可安装到桌面，Service Worker 预缓存应用外壳，二次访问离线可用
- ⌨️ **自定义快捷键**: 除方向键与 Esc 外均可重新绑定，支持冲突检测
- 💾 **数据管理**: 自动保存、导入/导出、链接分享、文件导入/导出、多步撤销
- 📱 **响应式设计**: 完美适配桌面和移动设备
- ⚡ **性能优化**: GPU加速、出现/移动/合并/分数跳字动画独立开关
- 🔧 **丰富设置**: 多种可配置选项提升游戏体验

## 快速开始

1. **直接在线游玩**
   - 访问[项目页面](https://thefurina.github.io/2048-game/)即可开始游戏

2. **本地运行**
   - 解压完整项目，保持 `index.html`、`css/`、`features/` 的相对目录结构不变
   - 推荐通过本地 HTTP 服务运行：

   ```bash
   # 在项目根目录执行
   python3 -m http.server 8000
   # 浏览器打开 http://localhost:8000
   ```

   - 也可以直接用现代浏览器打开 `index.html`，但部分浏览器会限制 `file://` 下的外部脚本加载

3. **部署到服务器**
   - 将整个项目目录上传到任意支持静态文件的 Web 服务器
   - 页面依赖 Tailwind CSS 与 Font Awesome 的 CDN 资源；使用局域网同步时会按需加载 PeerJS。如需完全离线部署，请自行本地化这些资源
   - 滑块字体已自托管在 `fonts/`，不依赖外部字体服务；PWA 离线依赖 HTTPS 或 localhost 环境

## 游戏玩法

### 基本规则
- 使用 **方向键** 或 **WASD** 键移动方块
- 相同数字的方块碰撞时会合并，数字相加
- 每次移动后，会在空白位置生成新的方块（2或4）
- 标准模式：达到2048即获胜并结算
- 无尽模式：没有获胜目标，尽可能获得高分

### 触摸控制
- 在移动设备上支持触摸滑动操作
- 向左/右/上/下滑动屏幕移动方块

## 功能详情

### 游戏模式
- **标准模式**: 目标达到2048，达成后弹出获胜结算，可重新开始或切换到无尽模式继续挑战
- **无尽模式**: 没有获胜目标，直到无法移动为止

### 网格大小
- **预设尺寸**: 3×3、4×4、5×5
- **自定义尺寸**: 支持3×3到10×10的任意矩形网格
- **正方形锁定**: 可选择保持网格为正方形
- **全尺寸支持**: AI 分析与 AI 自动操作适用于所有网格尺寸

### 难度级别
- **简单**: 4出现的概率40%，得分乘数1
- **中等**: 4出现的概率10%，得分乘数1（默认）
- **困难**: 4出现的概率5%，得分乘数1.5

### AI游戏分析
- **算法分析（默认）**: 本地启发式搜索，无需联网即可推荐最佳移动
- **AI分析**: 调用兼容 OpenAI Chat Completions 的接口，返回最佳移动、合并机会、状态评估、得分潜力与文字建议
- **最佳移动方向**: 分析当前棋盘，推荐最佳移动方向，可隐藏/显示
- **合并机会评估**: 识别潜在的合并机会
- **游戏状态评估**: 评估当前游戏状态（安全/警告/危险）
- **得分潜力分析**: 预测未来得分潜力
- **重新生成**: AI 分析模式下可重新请求结果
- **模式记忆**: 分析模式选择会被保存，下次打开自动沿用
- **API自定义**: 在设置中配置 Base URL、API Key、模型，并支持获取模型列表与检查可用性
- **优化选项**:
  - **仅请求最佳移动方向**: 跳过详细分析，响应更快
  - **允许推荐撤销**: AI 可建议撤销上一步来挽回失误

### AI自动操作
- **自动游玩**: 根据当前分析模式（算法分析 / AI分析）连续执行最佳移动
- **运行控制**: 支持开始、暂停、继续、停止，并在状态下显示已执行步数
- **状态徽标**: 页面内显示自动操作状态，可直接暂停或关闭
- **游戏联动**: 游戏暂停时自动暂停，继续游戏后自动恢复；游戏结束或无法移动时自动停止
- **屏幕常亮**: 可选在自动操作期间通过 Wake Lock API 阻止屏幕休眠（不支持时自动忽略）
- **撤销支持**: 开启“允许推荐撤销”后，自动操作可以执行撤销
- **快捷入口**: AI 分析面板中的“自动操作”按钮，或默认快捷键 `T`

### 自定义主题
- **预设主题**: 浅色、深色、跟随浏览器
- **完全自定义**:
  - 基础颜色（背景、主色调、次色调、网格、空单元格、滚动条）
  - 滑块颜色（每个数字对应的背景色和文字颜色，含 2048 以上的超大数字）
  - 模态框颜色
  - 颜色透明度（基础颜色与模态框颜色）
- **实时预览**: 自定义时可实时预览效果
- **保存/加载**: 自定义主题可保存到本地
- **导入/导出**: 可将选定主题项导出为 JSON 文件，或从 JSON 文件导入主题

### 多设备同步
- **6 位连接码**: 通过 PeerJS / WebRTC 快速配对，创建方生成 6 位连接码，另一台设备输入后即可连接
- **手动模式**: 信令服务器不可用时，可展开手动模式，双方互换压缩后的长连接码完成点对点连接
- **实时同步**: 连接保持期间，游戏状态与设置更改会自动同步
- **包含设置**: 可选择是否同步设置数据
- **同步指示器**: 顶部状态条实时显示连接状态，可点击查看详情或断开
- **纯点对点数据**: 信令仅用于建立连接，游戏数据通过 WebRTC Data Channel 在设备间直连传输
- **兼容提示**: 不支持的浏览器会显示提示

### 振动反馈
- **总开关**: 一键启用/关闭振动
- **分项控制**: 合并振动、获胜振动、失败振动独立开关
- **能力检测**: 自动检测浏览器是否支持振动 API，不支持时显示提示

### 全屏模式
- **一键全屏**: 调用浏览器原生全屏 API（兼容 webkit / ms 前缀）
- **沉浸UI**: 进入全屏时自动隐藏标题、按钮、模式说明等次要元素
- **方向锁定**: 在支持的设备上尝试锁定竖屏以获得最佳体验

### 多语言支持
- **支持语言**: 简体中文（zh）、英文（en）、日文（ja）
- **自动跟随**: 默认跟随浏览器语言
- **手动切换**: 设置中可手动选择语言，所有界面文案实时更新

### 声音效果
- **默认关闭**: 首次进入不会播放任何声音，需要时在设置中开启
- **场景开关**: 移动、合并、获胜、失败四类音效独立开关
- **音量调节**: 0–100% 滑块，实时生效
- **试听**: 每个场景可单独试听当前音效
- **内置音效**: 使用 Web Audio API 实时合成，无需下载音频文件
- **自定义音频**: 每个场景可上传本地音频替换内置音效（不超过 1MB）
- **仅存本机**: 自定义音频保存在浏览器本地，不参与数据导出，避免分享数据体积膨胀
- **恢复默认**: 可一键恢复为内置音效
- **状态记忆**: 总开关、音量、分项开关与自定义音频都会自动保存
- **展开动画**: 关闭时子项与分隔线同步收起，不留残余间距

### 滑块字体
- **五种选择**: 系统字体、Inter（默认）、Nunito、Press Start 2P、JetBrains Mono
- **仅作用于数字**: 字体只影响滑块上的数字，不改变其他界面文本
- **按需加载**: 首次选择某个字体时才请求对应文件，已加载不会重复请求，首屏不请求字体
- **自托管数字子集**: `fonts/` 下的 woff2 仅包含 0–9，单个文件约 1.3–3.2 KB
- **加载反馈**: 显示「加载中 / 已应用」，失败时提示并自动回退系统字体
- **持久化**: 选择会保存，刷新或导入设置后自动恢复
- **不溢出**: 宽字体与 5、6 位数字自动缩放，保持滑块内居中不溢出
- **键盘可用**: 选择器支持方向键、Enter 与 Esc 操作，并与其他下拉框互斥展开

### 分享战绩
- **获奖结算**: 标准模式达成目标后，结算弹窗显示「分享战绩」
- **图片生成**: 通过 Canvas 生成 1080×1350 竖版战绩图，包含棋盘、分数与文案
- **系统分享**: 支持 Web Share API 时直接调用系统分享面板
- **自动下载**: 不支持系统分享时自动下载图片
- **失败提示**: 图片生成失败会给出提示，方便重试

### 自定义网页标题
- **入口**: 设置 → 外观 → 网页标题
- **占位符**: 支持 `{pageTitle}`、`{mode}`、`{difficulty}`、`{gridRows}`、`{gridCols}`、`{grid}`、`{score}`
- **默认回退**: 留空时使用内置的动态标题规则
- **实时更新**: 游戏模式、难度、网格或分数变化后标题同步刷新

### PWA 与离线
- **可安装**: 提供 manifest 与图标，可安装到桌面或移动主屏
- **多语言清单**: 根据当前语言切换 `manifest/` 下的中文、英文、日文清单
- **离线缓存**: Service Worker 预缓存应用外壳，二次访问可离线启动
- **安全环境**: Service Worker 需要 HTTPS 或 localhost

### 数据管理
- **自动保存**: 游戏进度自动保存到本地存储
- **文本导出/导入**: 支持 Base64 与 Base91 两种编码方式
- **导出为文件**: 将当前游戏状态导出为 `.txt` 文件
- **导出为链接**: 生成包含压缩数据的分享链接，打开链接后会提示自动导入
- **从文件导入**: 选择本地数据文件恢复游戏状态
- **包含设置**: 导出或链接分享时可选择是否携带设置数据

- **撤销功能**: 支持最多10步撤销（可通过 `Ctrl/⌘+Z` 触发）
- **数据清除**: 清除所有本地数据

## 键盘快捷键

下表为默认快捷键，除方向键与 Esc 固定可用外，其余按键均可在「设置 → 操作 → 快捷键设置」中重新绑定，并支持冲突检测。

| 快捷键 | 功能 |
|--------|------|
| **方向键 / WASD** | 移动方块 |
| **P / ESC** | 暂停 / 继续游戏 |
| **Ctrl / ⌘ + Z** | 撤销上一步（最多10步） |
| **R** | 重新开始游戏 |
| **N** | 切换到标准模式 |
| **E** | 切换到无尽模式 |
| **G** | 循环切换网格大小（3 / 4 / 5） |
| **L** | 打开AI分析面板 |
| **T** | 开始 / 暂停 / 继续 AI 自动操作 |

> 弹窗（设置、AI 分析、快捷键等）支持按 **Esc** 或浏览器返回键关闭最上层弹窗；若同时打开了多个弹窗，返回键会逐层关闭。

## 技术特性

- **前端技术**: HTML5、CSS3、原生JavaScript（ES6+）
- **样式框架**: Tailwind CSS（CDN）
- **图标库**: Font Awesome 6
- **响应式设计**: 媒体查询和Clamp函数
- **模块化架构**: 模块加载器 + Manifest 模块清单，支持按需加载、依赖校验、DOM 注入、模块 API 校验、样式校验与失败降级
- **样式模块化**: 功能样式拆分到 `css/modules/`，按模块按需加载
- **本地存储**: 使用 LocalStorage 保存游戏状态与设置
- **动画效果**: CSS transitions和keyframes
- **GPU加速**: 使用translateZ提升性能
- **跨设备通信**: WebRTC Data Channel + PeerJS（公共信令服务器，数据点对点）
- **数据压缩**: CompressionStream / DecompressionStream 用于分享链接与手动连接码
- **设备能力**: Wake Lock API、Vibration API、Fullscreen API、Web Share API
- **声音**: Web Audio API 实时合成内置音效，自定义音频解码后经 AudioBufferSourceNode 播放
- **字体加载**: FontFace API 按需加载自托管的数字子集 woff2，未加载时自动回退系统字体
- **分享图生成**: Canvas 2D 绘制战绩图片
- **PWA**: Service Worker 预缓存应用外壳，多语言 manifest 可安装到桌面
- **国际化**: i18n 模块化翻译（zh / en / ja），支持运行时切换
- **弹窗导航**: 模态框栈 + History 守卫，Esc 与浏览器返回键都能关闭最上层弹窗
- **无障碍**: ARIA标签和键盘导航支持

> 游戏启动时会检测 Promise、Fetch、CSS `@layer`、可选链等特性，不满足时会显示浏览器兼容提示。局域网同步需要支持 WebRTC 的浏览器，并需要能够访问 PeerJS 公共信令服务器；屏幕常亮依赖 Wake Lock API，不支持时会自动忽略；振动反馈需要支持 Vibration API 的设备；分享链接的压缩导出依赖 CompressionStream / DecompressionStream，不支持时会回退或提示。
>
> 声音效果依赖 Web Audio API，不支持时不会播放且不影响游戏；滑块字体依赖 FontFace API，加载失败会自动回退系统字体；PWA 离线缓存与系统分享需要 HTTPS（或 localhost）环境。

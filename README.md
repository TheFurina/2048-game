## 主要功能

- 🎮 **多种游戏模式**: 标准模式和无尽模式
- 📐 **可变网格大小**: 支持3×3到10×10的自定义网格
- 🎯 **难度级别**: 简单、中等、困难三种难度
- 🤖 **AI游戏分析**: 实时分析最佳移动方向和游戏状态，可自定义API配置
- 🎨 **主题定制**: 支持浅色、深色、跟随浏览器以及完全自定义主题
- 📲 **多设备同步**: 蓝牙同步与局域网（WebRTC）同步，跨设备继续游戏
- 📳 **振动反馈**: 合并、获胜、失败等关键时刻触觉反馈，可分项开关
- 🖥️ **全屏模式**: 一键全屏沉浸游玩，自动隐藏次要UI
- 🌐 **多语言支持**: 中文与英文界面，可跟随浏览器自动选择
- ⌨️ **自定义快捷键**: 全部按键可重新绑定，支持冲突检测
- 💾 **数据管理**: 游戏进度保存、导入/导出、撤销多步
- 📱 **响应式设计**: 完美适配桌面和移动设备
- ⚡ **性能优化**: GPU加速、滑块出现/移动/合并动画独立开关
- 🔧 **丰富设置**: 多种可配置选项提升游戏体验

## 游戏玩法

### 基本规则
- 使用 **方向键** 或 **WASD** 键移动方块
- 相同数字的方块碰撞时会合并，数字相加
- 每次移动后，会在空白位置生成新的方块（2或4）
- 标准模式：达到2048获胜
- 无尽模式：尽可能获得高分

### 触摸控制
- 在移动设备上支持触摸滑动操作
- 向左/右/上/下滑动屏幕移动方块

## 功能详情

### 游戏模式
- **标准模式**: 目标达到2048，达成后可继续挑战更高分数
- **无尽模式**: 没有获胜目标，尽可能获得更高分数

### 网格大小
- **预设尺寸**: 3×3、4×4、5×5
- **自定义尺寸**: 支持3×3到10×10的任意矩形网格
- **正方形锁定**: 可选择保持网格为正方形

### 难度级别
- **简单**: 4出现的概率40%，得分乘数1
- **中等**: 4出现的概率10%，得分乘数1（默认）
- **困难**: 4出现的概率5%，得分乘数1.5

### AI游戏分析
- **最佳移动方向**: 分析当前棋盘，推荐最佳移动方向
- **合并机会评估**: 识别潜在的合并机会
- **游戏状态评估**: 评估当前游戏状态（良好/一般/危险）
- **得分潜力分析**: 预测未来得分潜力
- **支持网格**: 3×3、4×4、5×5标准网格
- **API自定义**: 在设置中配置Base URL、API Key、模型、温度、最大Tokens

### 自定义主题
- **预设主题**: 浅色、深色、跟随浏览器
- **完全自定义**:
  - 基础颜色（背景、主色调、次色调等）
  - 滑块颜色（每个数字对应的背景色和文字颜色）
  - 模态框颜色
- **实时预览**: 自定义时可实时预览效果
- **保存/加载**: 自定义主题可保存到本地

### 多设备同步
- **蓝牙同步（Beta）**: 通过Web Bluetooth在两台设备间同步游戏状态，支持PIN码校验、断线重连
- **局域网同步（Beta）**: 基于WebRTC Data Channel，通过手动交换SDP完成点对点连接，无需中心服务器
- **同步指示器**: 顶部状态条实时显示连接状态，可点击查看详情或断开
- **兼容提示**: 不支持的浏览器会显示"不可用"提示，同步功能均以Beta状态提供

### 振动反馈
- **总开关**: 一键启用/关闭振动
- **分项控制**: 合并振动、获胜振动、失败振动独立开关
- **能力检测**: 自动检测浏览器是否支持振动 API，不支持时显示提示

### 全屏模式
- **一键全屏**: 调用浏览器原生全屏 API（兼容 webkit / ms 前缀）
- **沉浸UI**: 进入全屏时自动隐藏标题、按钮、模式说明等次要元素
- **方向锁定**: 在支持的设备上尝试锁定竖屏以获得最佳体验

### 多语言支持
- **支持语言**: 简体中文（zh）、英文（en）
- **自动跟随**: 默认跟随浏览器语言
- **手动切换**: 设置中可手动选择语言，所有界面文案实时更新

### 数据管理
- **自动保存**: 游戏进度自动保存到本地存储
- **数据导出**: 将当前游戏状态导出为Base64编码文本
- **数据导入**: 从Base64编码文本导入游戏状态
- **数据复制**: 一键复制导出数据到剪贴板
- **撤销功能**: 支持最多10步撤销（可通过 `Ctrl+Z` 触发）
- **数据清除**: 清除所有本地数据

### 设置选项
- **游戏性能**:
  - GPU加速（提升动画性能）
  - 滑块出现动画开关
  - 滑块移动动画开关
  - 滑块合并动画开关
- **触觉反馈**:
  - 振动总开关
  - 合并 / 获胜 / 失败振动分项开关
- **外观设置**:
  - 主题选择（自动/浅色/深色/自定义）
  - 自定义主题配置入口
- **数据管理**:
  - 数据导入/导出
  - 蓝牙同步（Beta）
  - 局域网同步（Beta）
  - 清除所有数据
- **AI**:
  - API Base URL / Key / 模型 / 温度 / 最大Tokens 配置
- **操作**:
  - 快捷键自定义（支持任意按键重新绑定与冲突检测）
  - 重置所有设置

## 键盘快捷键

下表为默认快捷键，所有按键均可在「设置 → 操作 → 快捷键设置」中重新绑定，并支持冲突检测。

| 快捷键 | 功能 |
|--------|------|
| **方向键 / WASD** | 移动方块 |
| **P / ESC** | 暂停 / 继续游戏 |
| **Ctrl + Z** | 撤销上一步（最多10步） |
| **R** | 重新开始游戏 |
| **N** | 切换到标准模式 |
| **E** | 切换到无尽模式 |
| **G** | 循环切换网格大小（3 / 4 / 5） |
| **L** | 打开AI分析面板 |

## 技术特性

- **前端技术**: HTML5、CSS3、原生JavaScript（ES6+）
- **样式框架**: Tailwind CSS（CDN）
- **图标库**: Font Awesome 6
- **响应式设计**: 媒体查询和Clamp函数
- **本地存储**: 使用LocalStorage保存游戏状态与设置（含旧Key迁移机制）
- **模块化加载**: 自实现 `ModuleLoader`，统一加载 `features/` 下功能模块并提供失败降级
- **动画效果**: CSS transitions和keyframes
- **GPU加速**: 使用translateZ提升性能
- **跨设备通信**: Web Bluetooth API、WebRTC Data Channel
- **无障碍**: ARIA标签和键盘导航支持

## 浏览器支持

- ✅ Chrome 60+
- ✅ Firefox 55+
- ✅ Safari 11+
- ✅ Edge 79+
- ✅ iOS Safari 11+
- ✅ Android Chrome 60+

> 蓝牙同步需要支持 Web Bluetooth API 的浏览器（如 Chrome / Edge 桌面端与 Android Chrome）；局域网同步需要支持 WebRTC 的浏览器；振动反馈需要支持 Vibration API 的设备。

## 项目结构

```
2048-game-main/
├── index.html                  # 主HTML文件（包含游戏入口、UI结构与核心游戏逻辑）
├── icon.png                    # 网站图标
├── LICENSE
├── css/
│   └── 2048.css                # 主样式表（含 --css-version 版本号）
├── .github/
│   ├── seo-head.html           # SEO 头部片段
│   └── workflows/
│       └── sync-to-seo.yml     # GitHub Actions 同步工作流
└── features/                   # 功能模块目录（由 module-loader.js 统一加载）
    ├── ai-analysis.js          # AI分析功能（网格评估、最佳移动建议）
    ├── ai-request.js           # AI API请求与设置管理（含状态管理器）
    ├── bluetooth-sync.js       # 蓝牙数据同步（Web Bluetooth）
    ├── custom-select.js       # 自定义下拉选择器组件
    ├── custom-theme.js         # 自定义主题颜色功能
    ├── data-transfer.js        # 数据导入/导出（Base64编码）
    ├── fullscreen-mode.js      # 全屏模式切换
    ├── i18n.js                 # 国际化多语言支持（zh / en）
    ├── manifest.js             # 模块清单（声明需加载的模块顺序）
    ├── module-loader.js        # 模块加载器（含失败降级）
    └── webrtc-sync.js          # 局域网同步（WebRTC Data Channel）
```
